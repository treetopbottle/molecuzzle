# Narratives

## First day

Noor opens Molecuzzle for the first time. Puzzle 1 shows a mystery molecule of three atoms in a column, a C with three small hydrogens, another C and an N, with dotted lines between them [Puzzle]. Noor clicks the top dotted line, and the status says two atoms still need bonds [Messages]; three clicks on the other make a triple Bond [Bond], all three atoms glow [Board], and it is Acetonitrile, with a fact about it [Panel]. Next puzzle brings Acetic acid, where the line between C and O takes two clicks for a double Bond.

Noor skips ahead to Puzzle 7 [List], and tries a second Bond on an OH, which already has all its bonds [Bond]. Stuck, Noor uses Show solution, reads it, clicks Reset and builds Serine alone, which marks it solved [Help]. The next day, in the same browser, the page opens on Puzzle 7, still showing Serine, with three Puzzles solved [Progress].
