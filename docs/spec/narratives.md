# Narratives

## First day

Noor opens Molecuzzle for the first time. Puzzle 1 shows a mystery molecule of an H, an O and another H, with dotted lines between them [Puzzle]. Noor clicks one dotted line, and the status says two atoms still need bonds [Check]; after the second, both H and the O glow [Valence], and it is Water, with a fact about it [Check]. Next puzzle brings Ammonia, and then Formaldehyde, where Noor clicks the line between C and O twice for a double Bond [Bond].

Noor skips ahead to Puzzle 11 [Puzzle] and tries a Bond across another one, which isn't allowed [Bond]. Stuck, Noor uses Show solution, reads it, clicks Reset and builds Glycine alone, which marks it solved [Help]. The next day, in the same browser, the page opens on Puzzle 11, with four Puzzles solved [Progress].

The end-to-end test is `tests/ui/narrative.spec.js`.
