# Narratives

## First day

Noor opens Molecuzzle for the first time. Puzzle 1 shows a mystery molecule of an H, an O and another H, with dotted lines between them [Puzzle]. Noor clicks one dotted line, and the status says two atoms still need bonds [Messages]; after the second, both H and the O glow [Board], and it is Water, with a fact about it [Panel]. Next puzzle brings Hydrogen cyanide, where the line between C and N takes three clicks for a triple Bond, and then Formaldehyde, with a double Bond [Bond].

Noor skips ahead to Puzzle 12 [List] and tries a Bond across another one, which isn't allowed [Bond]. Stuck, Noor uses Show solution, reads it, clicks Reset and builds Glycine alone, which marks it solved [Help]. The next day, in the same browser, the page opens on Puzzle 12, still showing Glycine, with four Puzzles solved [Progress].
