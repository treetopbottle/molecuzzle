# Finish a plan

1. Move what should outlive the plan: behavior into the spec, choices into `docs/decisions.md`, leftovers into the backlog. Commit.
2. [Review](review.md) the decisions against the code and the spec. Deal with the findings in new commits.
3. **Checkpoint.** Show what moved and the review. After an OK, set the status to `Done (<date>)`, in the plan and in the table in `docs/plans/README.md`, and commit.
