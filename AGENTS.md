# AGENTS.md

For coding agents. Read these first:

- @README.md: what this is, where things are, and the commands.
- @CONTRIBUTING.md: the working agreement, the docs and the style.

On top of those:

- **Read only what the task needs:** the active plan, the spec rules it names and the decisions they cite. Don't read finished plans or old reviews unless asked.
- **A test file already on disk is not an approved one.** Only an OK at the checkpoint approves tests.
- **Commit only when asked, and with a pathspec** (`git commit -- <paths>`). A workflow step that says commit counts as asked.
