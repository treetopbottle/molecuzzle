# AGENTS.md

For coding agents. Read these first:

- @README.md: what this is, where things are, and the commands.
- @CONTRIBUTING.md: the working agreement, the docs and the style.

On top of those:

- Commit only when asked, and with a pathspec (`git commit -- <paths>`)
- Use Conventional Commits, ask the user if you do not know what that is
- Do not add attribution to any commit message
